# **App Name**: CompanyCraft

## Core Features:

- Company Management: Allow players to create and manage companies, including setting up different ranks and inviting/removing members.
- Financial System: Implement a taxation system based on the number of employees and the company's capital, along with a stock system reflecting the company's worth. Integrates with CMI Vault for currency management.
- Task Assignment: Enable company leaders to assign tasks to members (e.g., collecting resources for a virtual warehouse) with specified rewards, penalties, and deadlines. Different ranks have different permissions.

## Style Guidelines:

- Primary color: Use Minecraft's grass block color (#7AC242) to give it a natural feel.
- Secondary color: Use a stone color (#A8A8A8) for backgrounds and less important UI elements.
- Accent: Gold (#FFD700) to highlight important actions or values, especially related to the company's financial status.
- Clear and readable font for in-game readability.
- Simple, Minecraft-themed icons for commands and actions.
- Easy-to-navigate command menus.
